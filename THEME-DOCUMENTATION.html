About LUXE Theme

LUXE is a premium Shopify theme designed for high-end fashion and luxury brands. It features a sleek, modern design with advanced e-commerce functionality including quick view, wishlist, product comparison, and seamless app integration. Built with performance and accessibility in mind, LUXE delivers exceptional shopping experiences on any device.

Key Features

  • 40+ Sections & Blocks: Highly modular layout with drag-and-drop section ordering
  • Advanced Product Display: Image zoom, 360° view, size guides, pre-order badges
  • Conversion Tools: Countdown timers, trust badges, flash sale, bundle offers
  • Customer Experience: Ajax cart, wishlist, compare products, quick view modal
  • Multi-Currency & Language: Built-in currency converter, localization support
  • Performance Optimized: Lazy loading, critical CSS, minified assets, Core Web Vitals ready
  • Accessibility: WCAG 2.1 AA compliant with full keyboard navigation
  • SEO Ready: Structured data, meta tags, optimized markup
  • Mobile-First: Fully responsive with touch-optimized interactions

Installation Guide

Get your LUXE theme up and running in minutes with these step-by-step instructions.

Prerequisites

  • A Shopify store (any plan)
  • LUXE theme .zip file (downloaded from Theme Forest or your account)
  • Admin access to your Shopify store

Step 1: Download the Theme

  1. Log in to your Shopify Admin.
  2. If purchased from Theme Forest, download the .zip file from your purchases page.
  3. If purchased from Shopify Theme Store, the theme will be automatically added to your store.

Step 2: Upload to Shopify

  1. In Shopify Admin, go to Online Store → Themes.
  2. Click Add theme → Upload zip file.
  3. Click Add file and select the luxe-theme-v1.0.zip file.
  4. Wait for the upload to complete (may take 1–2 minutes).

⚠️ Important

Do not delete or unpublish your current theme until you've confirmed LUXE works correctly. Keep a backup theme as a safety net.

Step 3: Activate the Theme

  1. After upload, find LUXE in your Unpublished themes section.
  2. Click Actions → Publish to make it live.
  3. Alternatively, click Customize to preview and edit before publishing.

Step 4: Initial Configuration

Once activated, complete these essential setup steps:

1. Upload Your Logo

  1. Go to Online Store → Themes → Customize.
  2. Open Theme settings → Logo.
  3. Upload your brand logo (PNG or SVG recommended, max 400px width).

2. Set Up Navigation Menus

  1. Go to Online Store → Navigation.
  2. Create your main menu (e.g., "Main Menu") with all important links.
  3. Return to the theme editor and assign this menu to the Header section.

3. Configure Homepage Sections

  1. In the theme editor, select the Homepage template.
  2. Add and arrange sections (hero, featured products, testimonials, etc.).
  3. Customize each section's content and styling.

4. Connect Social Media

Add your social media URLs under Theme settings → Social media to display icons in the header and footer.

Step 5: Recommended Apps

Enhance your store with these compatible apps:

  • Reviews: Judge.me, Loox, Yotpo, Appixen
  • Email Marketing: Klaviyo, Mailchimp
  • Upsell: Zipify, ReConvert, Appixen Upsell
  • Live Chat: Gorgias, Tawk.to

Theme Editor Overview

The LUXE theme uses Shopify's intuitive theme editor for drag-and-drop customization without any coding.

Accessing the Theme Editor

  1. Go to Online Store → Themes in your Shopify Admin.
  2. Find the LUXE theme (published or unpublished).
  3. Click Customize to open the theme editor.

Editor Layout

  • Left sidebar: Sections tree - click to edit each section's settings and blocks
  • Main preview: Live preview of your store updating in real-time
  • Right sidebar: Theme settings (global) and the selected section's settings

Working with Sections

  • Add Section: Click "Add section" button at the bottom of the left sidebar
  • Reorder: Drag and drop sections in the left sidebar to change layout
  • Remove: Click the trash icon next to a section in the sidebar
  • Edit: Click any section to reveal its settings in the right sidebar

Theme Settings

Global settings are organized into categories:

Colors & Typography

Set brand colors, font families, heading styles, and font sizes

Layout

Container width, spacing, border radius, and grid settings

Header

Logo, navigation, sticky behavior, and mobile menu style

Footer

Newsletter, social icons, payment icons, and legal links

Product Pages

Image zoom, ratings, share buttons, inventory display

Cart & Checkout

Cart drawer, express checkout, notes, shipping calculator

Blocks

Many sections support blocks - repeatable content items you can add, remove, and reorder:

  • Mega Menu: Add up to 10 blocks per menu item
  • Footer: Add multiple info/social/link columns
  • Hero Slider: Add unlimited slides with text, images, and buttons
  • Product Carousel: Add heading, collection, and optional promo

Previewing Changes

Use the preview toolbar to view your store on different devices:

  • Desktop: Full-width desktop view (default)
  • Tablet: iPad viewport
  • Mobile: iPhone viewport
  • Landscape: Mobile landscape orientation

Saving & Publishing

  1. Click Save to save your changes (they're stored but not yet live).
  2. Click Publish to make changes live immediately.
  3. Use View published theme to exit editor and view the live store.

💡 Pro Tip

Your changes are saved automatically every 30 seconds and when you navigate away. But always click Save before leaving to ensure recent edits are stored.

Theme Architecture

Layout Flow

theme.liquid
├── <head>
│   ├── Meta tags (SEO)
│   ├── CSS (critical inline + theme.css)
│   ├── Schema structured data
│   └── Favicon
├── <body>
│   ├── Skip to content link
│   ├── Announcement bar (if enabled)
│   ├── Header (section)
│   ├── Main content (template-specific)
│   ├── Cart drawer (snippet)
│   ├── Wishlist drawer (snippet)
│   ├── Compare drawer (snippet)
│   ├── Quick view modal (snippet)
│   ├── Pincode checker (floating)
│   ├── Floating chat buttons
│   ├── Cookie consent banner
│   ├── Toast notifications
│   └── Footer (section)

Data Flow

  1. Settings → Theme Settings → All sections access via settings.setting_id
  2. Products → Collection loop → Product card snippet
  3. Cart → Liquid object → Cart drawer snippet
  4. Customer → Shopify object → Account links

Logo Options

Navigation

How to Assign Templates

  1. Create a new page: Online Store → Pages → Add page.
  2. In the Theme template dropdown, select the desired template (e.g., "page.contact").
  3. Save the page.
  4. For collections, edit a collection and select a template under Theme template.
  5. For products, edit the product and select a template under Theme template.

Creating Custom Templates

Create new templates for specific use cases:

Option 1: Duplicate Existing

  1. Go to Online Store → Themes → Actions → Edit code.

Troubleshooting

Common Issues & Solutions

1. Cart not updating

  • Check if luxe-theme.js loads correctly
  • Verify no JavaScript errors in console (F12)
  • Ensure cart object exists
  • Clear theme cache in Shopify admin

2. Styles not applying

  • Clear browser cache (_hard refresh: Ctrl+F5)
  • Clear theme cache in Shopify admin
  • Check CSS specificity
  • Verify CSS variables are defined

3. Sections not appearing

  • Verify schema has presets defined
  • Check section file exists in /sections/
  • Ensure valid JSON in schema (use JSON validator)
  • Section must be added to template JSON

4. Liquid rendering errors

  • Check for missing/undefined variables
  • Verify filter syntax (e.g., | money)
  • Use {{ variable | json }} for debugging
  • Check for unclosed tags

5. Images not loading

  • Verify loading: 'lazy' attribute
  • Check image URL filters correct
  • Ensure images exist in Shopify admin

6. Mega menu not working

  • Confirm nav_link_title matches menu item exactly
  • Verify block is added to header section
  • Check JavaScript console for errors

7. Currency converter not showing

  • Enable in Theme Settings → Currency & Language
  • Enter valid ExchangeRate-API key
  • Ensure enable_currency_converter is checked

Debug Mode

Enable debug mode by adding ?debug=1 to URL to see detailed console logs.

Frequently Asked Questions (FAQ)

How do I update the theme?

  1. Download the latest version from your account
  2. Go to Online Store → Themes
  3. Click Actions → Upload zip file
  4. Publish the new theme (your current theme remains as backup)

Can I use this theme on multiple stores?

Each theme license is for one store only. You'll need to purchase additional licenses for additional stores. Contact us for bulk licensing options.

Is the theme compatible with Shopify's latest version?

Yes. LUXE is built on Shopify Online Store 2.0 and is fully compatible with the latest Shopify features and standards. We regularly update the theme to maintain compatibility.

How do I add a new language?

  1. Enable multiple languages in Settings → Languages
  2. Install a translation app (e.g., Weglot, Langify)
  3. Translate your content using the app's interface

Can I remove the "Powered by Shopify" footer?

Yes. Go to Online Store → Themes → Customize → Theme Settings → Footer and disable Show powered by Shopify. Please note that removing this attribution may violate Shopify's terms of service for certain theme types.

How do I add a custom section?

Create a new file in /sections/ with a {% schema %} block defining settings and blocks. Then add it to your template JSON. See Adding Custom Features for examples.

Why are my images blurry or pixelated?

Upload high-resolution images (minimum 1200×1200px for product images). Use Shopify's CDN which automatically serves optimized WebP images to supported browsers. Enable Image Zoom and Lazy Loading in theme settings for better performance.

Why is my cart not updating?

Check for JavaScript errors in the browser console. Ensure the AJAX endpoints /cart/add.js, /cart/change.js are accessible. Clear theme cache and verify no app conflicts.
